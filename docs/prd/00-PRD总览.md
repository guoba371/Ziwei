## 3. 通用业务规则

### 3.1 输入最小化

- 默认只收三项：出生公历年月日、性别、（可选）出生时辰。
- 未填时辰时按午时（时辰序号 5）处理，结果页标注"时辰未确认，结果供参考"。
- 禁止要求手机号、身份证等实名信息；收货信息由平台闭环，自建 H5 不收集。

### 3.2 内容生成两条路径

- 路径 A（查表，推荐用于商品 1/2/5/6b）：按 `key = YYYY-MM-DD-时辰序号-性别` 检索 v4.0 数据集（JSON Lines），取 13 维解读 `c.overview/personality/love/career/wealth/health/family/children/move/friends/home/spirit/parents` 与命宫主星 `ms`。零算力、内容稳定，与"时辰可选"口径一致（数据集未做真太阳时校正）。
- 路径 B（实时排盘，用于商品 3/4/6a）：调用 `lib/ziwei` 引擎，需要时辰与出生地，输出完整命盘 JSON 供海报渲染与流年推算。

### 3.3 数据集落地

- 下载 Release v4.0-13d 的 77 个年份文件（zstd，压缩后约 161 MB），解压约 56.6 GB。
- 入库方案（二选一）：SQLite 分年份建表 / Postgres 单表按 key 索引。MVP 阶段可先只入库近 40 年（1987-2026），覆盖目标客群出生年。
- 内容过滤：入库时移除解读内标注《天纪》集数与时间码的倪师原话引用（CC BY-NC-SA 禁止商用），替换为同义自撰句。

### 3.4 交付与发货

- 店铺类目：虚拟商品/数字内容；标题与详情注明"电子版、拍下即发、无实物"。
- 交付物：解锁码 + H5 结果页链接（站内私信/自动回复），或成品 PDF。
- MVP：下单后用店铺自动回复话术 + 半人工发货；日单量稳定后接第三方自动发货工具（按平台当前开放的虚拟商品履约方式评估）。
- 售后：因虚拟商品属性，写明"拍下后不支持退款，信息填错可免费重算一次"。

### 3.5 合规基线（所有商品强制）

- 商品详情页固定免责声明："本产品为传统文化趣味解读与性格分析，不构成医疗、投资、婚恋等任何决策建议。"
- 全链路禁词遵循 `docs/xhs/商品命名总览.md` 的禁词替换表；健康维度只写生活方式建议。
- 署名：H5 与 PDF 页脚标注"数据来源：紫微斗数开源解读数据集（作者：王多鱼AI，CC BY 4.0）"。
- 隐私：自建 H5 的隐私声明写明仅收集生日与性别用于生成内容，不存储超过 7 天或按最小保留原则处理。

## 4. 通用指标体系

- 流量：笔记曝光 → 进店点击率；内容号到店引流率。
- 转化：商品点击 → 下单率；下单 → 支付率；咨询转化率。
- 履约：自动发货成功率；从支付到交付耗时（目标 < 60 秒）。
- 传播：晒单率（晒单数/成交数，目标 > 5%）；结果页分享点击率。
- 经营：客单价、退款率（目标 < 3%）、复购率、单店月 GMV。

## 5. 通用里程碑

- M0 准备期（第 1 周）：数据集下载入库、H5 结果页 MVP、店铺类目与保证金、内容号注册。
- M1 验证期（第 2-4 周）：商品 1 上架，日发 3 条笔记，目标 100 单，验证转化率与发货链路。
- M2 放量期（第 5-8 周）：商品 2/5 上架，接自动发货，目标日 50-200 单。
- M3 提价期（第 9 周起）：商品 3/4/6 上架，首页搭价格梯度，目标客单价 > ¥12。

## 6. 风险与对策

- 平台风控：类目敏感，随时可能限流/下架 → 多账号矩阵、话术严格自查、不压单一爆款。
- 数据口径差异：v4.0 按旧亮度默认生成，与实时重排的星曜亮度可能不一致 → 同价商品内统一只用一种路径，避免混合输出。
- 退款与恶意举报：写明不退规则 + 一次免费重算兜底；客服话术统一走"文化娱乐"口径。
