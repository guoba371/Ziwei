# PRD 06：升单品组合（起名手册 / 全家图谱）

## 1. 产品定义

- 两个提升客单价的商品，不独立获客，靠商品 1/2/3 的成交页与结果页引流：
  - 6a 新生儿五行起名灵感手册：生日定制 60 组名字 + 解析。
  - 6b 全家紫微人格图谱：三人合集报告 + 家庭相处建议。

## 2. 目标用户与场景

- 6a：孕妈/新手父母，母婴赛道高客单；场景为"出生后第一份仪式感礼物"。
- 6b：情侣合盘用户顺势升单；场景为"给爸妈也测一份"。

## 3. 商品信息

- 6a 主推名：新生儿五行起名灵感手册｜生日定制 60 组名字
- 6a 备选名：宝宝起名｜生日定制名字库+解析
- 6a SKU：¥29.9（60 组名字分三档：常用字 / 文雅风 / 中性风，每组含五行属性 + 寓意一句话）。
- 6b 主推名：全家紫微人格图谱｜三人合集报告
- 6b SKU：¥19.9（三份人格图鉴精简版 + 家庭相处模式建议）。

## 4. 用户流程

- 6a：下单 → 输入宝宝生日（时辰可选）+ 姓氏 + 性别 → 收 PDF（名字清单 + 解析）。
- 6b：下单 → 输入三人出生日期 → 收三份图鉴 + 一张全家拼图卡。

## 5. 功能需求

- FR-1（6a）起名逻辑：路径 B 排盘取五行局与命宫主星，从名字库按喜用倾向筛选；名字库自建 ≥ 2000 组，人工审核避免生僻字与歧义，并提示"以民政局/户籍注册规则为准"。
- FR-2（6a）PDF：封面 + 使用说明 + 三档名字 + 五行解析 + 取名建议（读音、笔画、含义）+ 免责声明。
- FR-3（6b）组合报告：复用商品 1 的查表与标签逻辑 × 3 人，加一段"三人相处模式"模板文案（性格互补/同频/磨合点）。
- FR-4 升单触发：商品 1 完整款结果页、商品 2 深度款结果页、下单后私信话术三处埋点。

## 6. 内容与数据规则

- 6a 红线：不承诺"改名字能改运"；五行表述改为"传统审美与文化寓意"角度。
- 6b 家庭建议只讲相处模式，不讲亲缘吉凶。
- 均含免责声明与数据署名。

## 7. 页面与体验要求

- 6a 商品主图放"名字列表内页预览"，降低信任门槛；详情页写明"不重名概率仅供参考，不做注册保证"。
- 6b 全家拼图卡设计为三人人格标签并排 + 一句家庭主题词。

## 8. 指标

- 升单转化：商品 1 完整款用户 → 6b 转化率 ≥ 8%；6a 月销 ≥ 50 单后评估独立投流。
- 6a 退款率 < 5%（高客单需更完善售后话术）；6b 退款率 < 3%。

## 9. 技术要点

- 6a 名字库独立维护（CSV/DB），支持按性别、风格、五行属性检索。
- 两商品均复用 H5 交付链路，不新增独立应用。

## 10. 验收标准

- 6a：任意生日 + 姓氏可生成 60 组名字 PDF，名字无生僻字与违禁组合。
- 6b：三人生日可生成组合报告与拼图卡，同输入结果恒定。
