# PRD 03：命盘星图海报（生日定制电子壁纸）

## 1. 产品定义

- 一句话：输入生日，生成一张设计感的紫微命盘星图海报/壁纸，高清无水印交付。
- 定位：视觉款；海报本身即晒图素材，赚传播与审美溢价。

## 2. 目标用户与场景

- 主用户：愿意为"好看 + 专属感"付费的年轻女性；礼物场景（生日礼物、纪念礼物）。
- 场景：刷到海报实物效果图笔记 → "把生日做成一张星图"的好奇 → 下单 → 收到图 → 换壁纸 + 发笔记。

## 3. 商品信息

- 主推名：专属命盘星图海报｜生日定制电子壁纸
- 备选名：把生日做成一张星图｜紫微命盘壁纸定制
- SKU：单张 ¥6.9（竖版 1080x1920）；两张装 ¥9.9（横竖各一）；加 ¥5 换第二套风格。
- 交付物：高清 PNG（300dpi 尺寸），水印仅在免费预览版出现。

## 4. 用户流程

1. 下单 → 收解锁码 + H5 链接。
2. 输入生日 + 时辰（此处建议必填，保证星盘准确；未填默认午时）+ 出生城市（可选，用于真太阳时）。
3. 选风格（3-5 套：水墨 / 星轨 / 敦煌色 / 极简黑金 / 梦幻粉彩）→ 免费预览（带水印小图）。
4. 输码解锁 → 下载无水印高清图。

## 5. 功能需求

- FR-1 排盘渲染：路径 B 调用引擎生成命盘，将 12 宫位、主星、四化渲染为矢量星图；支持出生城市真太阳时校正。
- FR-2 风格模板：3-5 套可替换配色与装饰模板，同一命盘数据结构复用。
- FR-3 下载交付：无水印 PNG；邮件或 H5 下载页交付，文件保留 7 天。
- FR-4 赠言定制：买家可加一行赠言（≤ 16 字，送人场景），渲染在海报角落。
- FR-5 升单钩子：结果页推"流年锦囊"。

## 6. 内容与数据规则

- 海报只呈现星盘元素与人格标签，不呈现运势类文字；赠言内容需过敏感词过滤。
- 署名与免责声明放在交付邮件与下载页页脚。

## 7. 页面与体验要求

- 预览图 < 2 秒出；风格切换即时刷新；移动端可长按保存。
- 视觉要求高于其他商品：这是"卖图片"的产品，每套风格出 3 张示例样机图（手机壁纸、相框装裱、桌面摆台）用于商品主图。

## 8. 指标

- 下单 → 支付率 ≥ 55%；两张装占比 ≥ 30%；晒单率 ≥ 15%（海报类天然高）；退款率 < 3%。

## 9. 技术要点

- 渲染层可用 Canvas/SVG 服务端生成 PNG（如 node-canvas / resvg），缓存同 key 结果避免重复计算。
- 风格模板与命盘数据解耦，新增风格不改排盘逻辑。

## 10. 验收标准

- 同一生日在 5 套风格下元素位置一致；高清图分辨率达标。
- 赠言含违禁词时给出提示并拒绝渲染。
