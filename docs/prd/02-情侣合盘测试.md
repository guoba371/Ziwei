# PRD 02：情侣合盘测试

## 1. 产品定义

- 一句话：输入两人的出生日期，免费看匹配度百分比与一句结论，付费解锁合盘详解的虚拟商品。
- 定位：情感赛道主力款 + 裂变引擎（天然"@对象来测"）。

## 2. 目标用户与场景

- 主用户：20-35 岁恋爱中/暧昧期女性；次级用户：闺蜜互测、结婚纪念日送礼。
- 场景：刷到"匹配度 92% 天生一对"笔记 → 拉对象一起测 → 免费看分数 → 为看"为什么"付费。

## 3. 商品信息

- 主推名：情侣合盘测试｜你们是天生一对还是欢喜冤家
- 备选名：紫微合盘匹配度测试｜输入你俩的生日
- SKU：基础款 ¥3.9（匹配度 + 契合点 3 条 + 相处提醒 2 条）；深度款 ¥6.9（合盘详解 + 关系阶段建议 + 合盘分享卡）。

## 4. 用户流程

1. 下单 → 收解锁码与 H5 链接。
2. 输入双方生日（+ 可选性别、时辰）→ 免费预览页：匹配度分数 + 一句结论 + 人格标签各一。
3. 输码解锁 → 合盘详解页（契合点、相处提醒、关系建议）。
4. 晒图：合盘卡片"我们匹配度 92%"带店铺水印。

## 5. 功能需求

- FR-1 匹配度计算：复用 `lib/ziwei/heming-knowledge.ts` 合盘比对逻辑，输出 0-100 分；规则参考命宫、夫妻宫、福德宫主星关系，纯娱乐口径，禁止"正缘/分手/离婚"表述。
- FR-2 双盘渲染：同时渲染两张简化命盘，突出命中宫位（夫妻宫、命宫、福德宫）。
- FR-3 合盘文案：由规则模板拼装（如命宫主星相同 → "你们性格同频，容易互相理解"），每单从候选句库组合，保证多样性。
- FR-4 分享卡：双人版卡片，含两人人格标签 + 分数 + 水印。
- FR-5 升单钩子：下单后推荐"全家图谱（3 人）"。

## 6. 内容与数据规则

- 数据来源：单盘 13 维解读用路径 A；合盘段落用路径 B 排盘 + 规则模板，不涉及倪师原话。
- 红线：不输出任何"会不会分手/离婚/正缘"类结论；分数区间文案全部中性化（90+ 高契合 / 70-89 较契合 / 50-69 有差异也有互补 / 50 以下"欢喜冤家，相处有挑战"）。

## 7. 页面与体验要求

- 免费预览页必须让"分数 + 双人标签"一屏可见；付费墙放"为什么是这个分数"。
- 移动端优先；结果页可切换 A/B 视角（"我们怎么看对方"）。

## 8. 指标

- 下单 → 支付率 ≥ 60%；深度款升单率 ≥ 15%；分享点击率 ≥ 8%；退款率 < 3%。

## 9. 技术要点

- 一次请求查两张盘的 key，合盘规则在服务端计算；结果可生成链接供对方直接查看（免输第二次）。

## 10. 验收标准

- 任意两组真实生日可出结果；匹配度计算在 2 秒内完成。
- 全程无分手/离婚/正缘等词；含免责声明与署名。
