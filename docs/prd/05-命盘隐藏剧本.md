# PRD 05：命盘隐藏剧本（前世今生趣味测试）

## 1. 产品定义

- 一句话：输入生日，出三个"隐藏剧本关键词"的纯娱乐趣味测试。
- 定位：第二引流款；纯娱乐无预测，平台合规风险最低，可做大量笔记内容。

## 2. 目标用户与场景

- 主用户：16-30 岁，喜爱"前世今生 / 今生命题 / 隐藏人格"类测试内容。
- 场景：刷到"我的今生命题是破局，你的是什么？" → 拍下 → 生成三个关键词 → 评论区对暗号。

## 3. 商品信息

- 主推名：你的命盘隐藏剧本｜紫微人格趣味测试
- 备选名：测测你的今生命题｜生日趣味测试
- SKU：¥0.99 一档（三关键词 + 三段小故事 + 一张剧本卡片）。

## 4. 用户流程

1. 下单 → 收解锁码 + H5 链接。
2. 输入生日 → 免费预览一个关键词（如"你的命盘里藏着一个字：破"）。
3. 输码解锁 → 三个关键词 + 三段故事化解读 + 剧本卡片。
4. 晒图：剧本卡片。

## 5. 功能需求

- FR-1 关键词生成：由命宫 + 福德宫 + 身宫的主星组合，从"命题字库"（破 / 守 / 逢 / 渡 / 归 / 争 / 隐 / 燃…）匹配 3 个字，规则确定性强。
- FR-2 故事化文案：每个关键词配 200-300 字第二人称小故事（"你曾在……你总在……"），模板 + 星曜词库拼装，全库 ≥ 500 段候选。
- FR-3 剧本卡片：竖版复古戏单风格卡片，含水印。
- FR-4 升单钩子：解锁页推"紫微人格图鉴完整版"。

## 6. 内容与数据规则

- 全产品不出现任何预测与吉凶表述；故事文案仅限文学化表达。
- 文案需人工审核一轮，确保无"你前世死于……"等可能引发不适的表达。

## 7. 页面与体验要求

- 视觉方向：旧戏台/戏单美学（朱红、藏青、米黄），与产品"剧本"概念一致。
- 免费预览到付费只隔一个按钮，减少流失。

## 8. 指标

- 下单 → 支付率 ≥ 65%；晒单率 ≥ 8%；退款率 < 2%（低价纯娱乐，预期最低）。

## 9. 技术要点

- 复用路径 A 查表取 `ms` 与盘结构；关键词映射表独立维护，可每周上新"命题字"。

## 10. 验收标准

- 同生日同性别结果恒定；全库文案过审无禁词与不适表达。
