# PRD 01：星系角色图鉴（已确认的首版）

状态：2026-10-24 用户确认采用原创问卷方向。保留原文件名以免旧链接失效；本文件替代此前的生日排盘方案。

## 1. 定义与边界

12 道日常情境题，按固定规则生成 8 种原创星系角色之一，提供相处风格描述和可保存的结果卡。定位为低价娱乐数字内容的体验原型，不是心理测评、命理服务或已获平台批准的商品。

- 商品暂定名：星系角色图鉴｜12道题发现你的相处风格·趣味测试电子版。
- 拟测试价格：人民币 2.9 元，单一 SKU；原型免费体验，不发生支付。
- 面向希望获得轻松自我观察和分享素材的成年用户。具体市场需求尚未验证。
- 不收集生日、性别、姓名、联系方式或他人信息。
- 不连接原紫微排盘库、数据集、AI、支付、会员、订单、私信或平台发货接口。
- 不承诺准确率、科学效度、成交率、销量、平台审核结果。

## 2. 用户流程

首页了解内容与娱乐性质 -> 开始答题 -> 逐题选择 -> 查看免费角色结果 -> 明确标识的演示解锁 -> 阅读四部分内容 -> 保存结果卡。

- 免费结果包括角色名、短句、三个特点、简介和三个答题倾向。
- 完整内容包括相处偏好、表达方式、容易忽略的地方、可以尝试的小行动。
- 每题四个选项，显式点击“下一题”，不自动跳题；最后一题按钮为“查看我的角色”。
- 返回上一题保留选择；修改后重新计算，不沿用旧结果。
- 可以从结果返回修改答案；清空并重新开始会重置答案与演示解锁状态。
- 首页提供角色目录和说明；目录预览明确标识“角色示例”，不冒充用户结果。

## 3. 题目与评分契约

版本：`atlas-v1`。题目、评分和角色内容在源码中版本化。

三个维度各四题，12 题交错呈现，每个选项计 0、1、2、3 分，每维范围 0–12。总分 >= 6 选右端，否则选左端；恰好 6 分的固定分界只是内容分类规则，不代表科学界限。

| 维度 | 左端（0） | 右端（12） |
| --- | --- | --- |
| expression | 安静观察 | 主动表达 |
| discovery | 熟悉节奏 | 新鲜体验 |
| connection | 条理分析 | 感受共鸣 |

按 expression/discovery/connection 的组合形成八个角色：000 观察者，001 守护者，010 寻路者，011 造梦者，100 构筑者，101 联结者，110 探索者，111 灵感家。

- 拒绝少答、多答、空答案、非整数和越界选项；不随机补全。
- 相同完整答案和内容版本必得相同结果；全部八个角色都可达。
- 倾向条表示本次题目得分，不显示“准确率”“人格概率”“人群占比”。
- 文案采用“从这次选择看”“你可能更偏好”；不贴优劣、疾病或关系宿命标签。

## 4. 页面要求

### 首页

品牌与本地体验标识、核心介绍、开始入口、单张角色示例、八角色目录、测试与隐私说明。只有明确的开始按钮推动主流程，不弹出营销弹窗。

### 答题页

显示题号、已答进度、当前问题、四个原生单选项、上一步与下一步。未选择时下一步不可用。键盘可以选项和前进，题目切换后将焦点移到题目。

### 结果页

展示结果、回答倾向和演示解锁区域。按钮必须写“演示解锁”，旁边说明“无需付款”；不能用假的支付成功提示。内容仅用真实答题结果，无假的加载分析动画。

### 结果卡

浏览器端 Canvas 绘制 1080 × 1440 PNG；含角色名、短句、特点、品牌和“原创娱乐问卷 · 非心理测评”。不包含原始答案、个人信息、店铺二维码或未授权外链。

下载同时提供可长按的图片预览，兼容移动浏览器限制。导出中禁用重复操作；失败后说明原因并允许重试，不宣称保存成功。

## 5. 数据与隐私

答案与演示状态只在 React 内存中保存，不使用 Cookie、localStorage、服务端或统计 SDK。刷新/关闭页面会清空。图片在本机生成。字体、图标与脚本从同源静态资源加载，无外部字体请求。

## 6. 视觉与可访问性

移动端优先，支持 360px 宽度至桌面。观测手册式视觉：浅纸色、钴蓝、清晰几何星轨；中文衬线标题与易读正文。动效只用于入场与状态切换，尊重减少动态效果设置。控件不少于 44px 触摸高度；原生单选、可见焦点、语义标题和文字标签。

## 7. 商业与合规限制

正式销售前必须另行核实平台类目准入、内容要求、站外跳转与履约、售后规则、隐私告知等。本原型不构成合规审批。

不能以换词掩盖命理服务；不能用免责声明免除全部责任；不能笼统写“虚拟商品一律不退”；不能靠多账号规避治理。暂不使用原仓库素材，不涉及其许可复用；未来引入内容时逐项核实权利，改写不自动消除授权限制。

## 8. 验收

1. 12 道题可顺序完成，未答无法继续；上一题保留选择。
2. 全部八个角色可达；同答案一致；非法输入不产生结果；修改答案会更新结果。
3. 免费/演示解锁状态明确，重测不残留旧解锁和旧图片。
4. PNG 尺寸正确、内容清晰、可下载，含娱乐说明，无答案泄漏。
5. 桌面与移动端无水平溢出；可键盘操作；无未处理浏览器错误。
6. 自动测试、TypeScript 检查、生产构建通过。

本阶段验收体验与功能，不将尚未采样的成交率、分享率或利润写成产品事实。
