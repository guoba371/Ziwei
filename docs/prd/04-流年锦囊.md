# PRD 04：流年锦囊（年度自我成长主题指南 PDF）

## 1. 产品定义

- 一句话：按出生日期生成某一年份的"年度主题 + 月度节奏 + 成长建议"电子指南 PDF。
- 定位：应季主力款（岁末年初流量高峰），客单价与信任度高于测试类。
- 包装策略：全面采用"自我探索 / 年度规划"话术，替代"运势预测"。

## 2. 目标用户与场景

- 主用户：23-40 岁，有年度复盘/规划习惯的人群；新年、生日两个购买节点。
- 场景：刷到"我的 2027 关键词：扎根"笔记 → 想生成自己的年度指南 → 下单 → 收到 PDF → 拍封面晒图。

## 3. 商品信息

- 主推名：2027 年度自我成长锦囊｜生日定制主题指南 PDF
- 备选名：今年你的关键词是什么｜生日定制年度指南
- SKU：标准版 ¥9.9（年度关键词 + 12 个月节奏 + 成长建议，约 12-15 页 PDF）；加急版 ¥19.9（额外含"季度复盘模板"与"能量补充清单"）。

## 4. 用户流程

1. 下单 → 收解锁码 + H5 链接（次年同名商品可复用 H5，参数切换年份）。
2. 输入生日 + 时辰（可选）+ 目标年份 → 免费预览：年度关键词 + 一季度节奏。
3. 输码解锁 → 在线完整阅读 + 下载 PDF。
4. 晒图：年度关键词卡片。

## 5. 功能需求

- FR-1 年度关键词：路径 B 引擎取本命盘 + 目标年份流年四化，按规则从关键词库（如"扎根 / 破局 / 蓄力 / 连接 / 整理 / 出发"）匹配 1 个主词 + 2 个辅词。
- FR-2 月度节奏：按流年宫位推进，每月一段"本月主题 + 建议行动"，12 段；文案全部用成长/行动语言。
- FR-3 PDF 生成：固定模板（封面、年度主题、月度节奏、成长建议、季度复盘、免责声明、署名），服务端生成。
- FR-4 年份切换：同一用户可购买任意目标年份；下单区分"2027 版"等 SKU。
- FR-5 升单钩子：读完页推"命盘星图海报"。

## 6. 内容与数据规则

- 只讲"主题 / 节奏 / 行动建议"，禁止具体事件预测（如"某月会升职"）、禁止财务与健康断言。
- 健康相关统一为"作息与精力管理建议"。
- 年度关键词库每月更新一批，保证同年同生日不同购买时间的用户看到一致结果（同 key 同结果，确定性原则）。

## 7. 页面与体验要求

- 免费预览首屏：年度关键词大字号 + 一句话释义，直接可晒。
- PDF 排版达到"愿意晒封面"的标准：标题页强视觉、正文易读、留白充足。

## 8. 指标

- 岁末年初（12-2 月）贡献全年销量 ≥ 50%；下单 → 支付率 ≥ 55%；退款率 < 3%；PDF 下载率 ≥ 90%。

## 9. 技术要点

- 引擎需支持流年层推算（仓库 `lib/ziwei` 已含大限/流年四化）。
- 流年起止口径二选一并全店统一：农历正月初一 或 立春；PRD 默认农历正月初一，页面向用户说明口径。

## 10. 验收标准

- 任意真实生日 × 任意目标年份可生成 PDF；同生日同口径结果恒定。
- 全文无事件预测、无禁词；含免责声明与署名。
