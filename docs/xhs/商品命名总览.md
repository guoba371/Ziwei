## 命名原则

1. 标题前 20 字必须含可检索关键词：生日测试 / 性格测试 / 人格 / 合盘 / 定制。
2. 绝对避开：算命、占卜、预测、改运、消灾、看相、命中注定、准、灵验。
3. 用"测试 / 图鉴 / 指南 / 手册 / 定制"做品类词，用情绪词做钩子。
4. 标题里放"电子版 / 虚拟商品 / 拍下即发"，降低咨询成本、符合虚拟商品类目要求。
5. 每个商品配一个"可晒图的结果名"，用户晒单时天然带品牌词。
